# Changelog

## 0.1.0 — release candidate

- Layered CSS core with design tokens, reset, fluid type, layout utilities and basic components.
- Optional modules and 41 standalone component packs.
- Dark/light Astro documentation with HTML playgrounds, component/class search and practical guides.
- Native input, disclosure, dialog and popover examples; advanced application integration requirements documented.
- Core measured at 3,313 bytes gzip (level 9); optional modules measured separately.

This is a locally prepared release candidate. A Git tag, GitHub release and npm publication have not been created. See docs/releasing.md.
