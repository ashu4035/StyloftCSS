# Component-only CSS

Use a standalone pack when you need one component family. Each file includes design tokens and the component dependencies listed below; it does not require styloft.min.css. Readable and minified versions are generated by npm run build under dist/components/. Download links appear above the examples on every component page.

## Buttons only

Copy dist/components/buttons.min.css into your site's CSS directory, then load it:

```html
<link rel="stylesheet" href="/css/buttons.min.css">
<button class="sl-btn">Save changes</button>
<button class="sl-btn sl-btn--outline">Cancel</button>
```

Button sizes, variants, signature effects and loading-spinner styles are included. The buttons pack excludes cards, forms, tables and the full layout/utility collection. To use layout helpers around your buttons, add the layout pack or use your site's layout CSS.

Other packs work the same way: components/cards.min.css, forms.min.css, headers.min.css, and so on. Pack names resolve through the package export components/* (for example, styloftcss/components/buttons), when consuming the repository as a package.

Standalone packs share identical token declarations, so they can be combined. For many components, the core plus optional modules can avoid duplicate shared CSS. Do not load both a standalone pack and the full core for the same component unnecessarily. Demo-only classes still require the documented demo extension stylesheet. Arbitrary mixtures of components need their corresponding packs; a cards pack does not style a nested form automatically.

## Mobile headers

The sl-header container switches to its native details Menu disclosure below 44rem of available width. Desktop navigation is hidden and removed from keyboard navigation at that size; normal links and the CTA are available inside the disclosure. Enter/Space opens it without JavaScript. The first five examples demonstrate the left/right/centered logo variants and top information bar. With motion allowed, the menu height opens and closes smoothly in supporting browsers.
